# Travel Companion

Progressive Web App para organizar y consultar viajes personales desde cualquier dispositivo.

## Requisitos

- Node.js 24 o una versión LTS compatible.
- pnpm 11.

## Desarrollo local

Instala las dependencias:

```bash
pnpm install
```

Inicia el servidor de desarrollo:

```bash
pnpm dev
```

## Comprobaciones

```bash
pnpm typecheck
pnpm lint
pnpm build
```

La compilación de producción se genera en `dist/`.
